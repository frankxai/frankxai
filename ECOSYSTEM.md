# The founder portfolio

A public guide to the work led by [Frank Riemer](https://github.com/frankxai).
Updated 3 November 2026.

The portfolio connects AI engineering, creator tools, original IP and practical education. Each brand has its own audience and purpose.

## Contribute at the source

Some organizations include mirrors of repositories maintained elsewhere. Use the owning repository's contribution instructions and current links before opening a change. Each repository defines its own license, release state and setup requirements.

For a product collaboration, workshop or joint demonstration, write to [frank@frankx.ai](mailto:frank@frankx.ai) with the audience, problem and outcome.
